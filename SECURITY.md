# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of **PixelTruth** seriously. If you believe you have found a security vulnerability in this project, please follow these steps:

1. **Do not create a public GitHub issue.**
2. Email your findings directly to ditthanjeganathan067@gmail.com.
3. Include as much information as possible:
   - A description of the vulnerability.
   - Steps to reproduce or proof-of-concept exploit.
   - Potential impact of the issue.

We will review the vulnerability report, provide an initial response within 48 hours, and coordinate a fix and public disclosure schedule responsibly.
