> A clean, modern web application designed to analyze image authenticity, inspect metadata, and detect digital manipulation.

---

## ✨ Features

- **Metadata Inspection:** Extract and display EXIF tags, camera details, and creation timestamps.
- **Error Level Analysis (ELA):** Highlight compressed or altered regions within digital images.
- **Responsive Interface:** Minimalist, user-friendly design optimized for all screen sizes.
- **Zero Dependencies:** Built with lightweight, modern web standards.

---

## 🚀 Quick Start

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Aditthan-07/Pixel-Truth.git
   cd Pixel-Truth
   ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Start the application:**
   ```bash
   python run.py
   ```

   Open **http://localhost:5000** in your browser.
